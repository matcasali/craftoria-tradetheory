Craftoria + Trade Theory

Craftoria with the Trade Theory player economy.

Install with Prism Launcher

  1. In Prism, click Add Instance, then Import.
  2. Paste this link and click OK:
  3. Prism downloads the pack. When its Blocked mods window appears, download the files it lists (below).
  4. Give the game at least 8 GB of memory: Edit instance, Settings, Java.

Update

  1. Select the instance, click Edit, open Modpack.
  2. The first time only: paste the same link into URL.
  3. Click Update Pack. Prism replaces what changed (your worlds and settings stay).

The server updates itself; when it restarts for a new version, update before you rejoin.

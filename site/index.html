Craftoria + Trade Theory

Craftoria with the Trade Theory player economy. It keeps itself up to date.

Install with Prism Launcher

  1. In Prism, click Add Instance, then Import.
  2. Paste this link and click OK:
  3. Press Launch. The first launch downloads every mod (a few minutes); later ones only what changed.

Mods to download by hand

Their authors allow downloads only from CurseForge's website. At the first launch a window lists them: click Open download page for each, then Download on CurseForge. The window picks the files up from your Downloads folder and the game starts by itself.

  • Antique Trading Ship antiquetradingship-1.4.0-neoforge-1.21.1.jar
  • Cataclysm: Spellbooks cataclysm_spellbooks-1.1.9-1.21.jar

If something asks for you

  1. "Press Launch again": the pack moved to a newer NeoForge and the instance was switched to it. Launch once more.
  2. A window listing mods to download by hand: a few mods allow downloads only from CurseForge's website. Open each page and click Download: the window finds the files in your Downloads folder and closes by itself.
  3. Give the game at least 8 GB of memory (Edit instance, Settings, Java) if it runs out.
